## 4. 已知问题与待裁决事项
1. **生成能力缺口（关键）**：原制作依赖 Imagegen（HTTP 429 额度耗尽）和 Runway（余额 0）。本环境无图像/视频生成模型，只能做程序化图形、真实字体合成、调色、运动、剪辑、音频。≥118 个候选名额中，需要写实/电影感画面的镜头无法由我生成。需要用户提供生成通道或素材，否则只能明确披露缺口，不得用占位或降质替代。
2. **UTC 与夜景冲突**：03:0x UTC 在深圳/东京/首尔/北京/杭州为白天（约 11:00–12:12），旧金山为前一日傍晚。原稿镜头写"夜晚"。当前美术保留夜景；是否改为当地白天或保留"电影化夜景"，需导演裁决。我不自行决定。
3. 署名：原稿片尾制作署名为"6.1Sol"，交接要求保留。续作部分是否追加 Claude 的署名/制作说明，由用户决定。
4. 文档间数字不一致（161 缺失 vs 118 名额、B09 vs B10 增量链）：以 PROGRESS_AND_CLAUDE_HANDOFF.md 和 B10 索引为准，实文件核验后重算。
5. 证据文件需保留不用：4 张截断 PNG（E3-08_v1、E6-02_v2、E9-07_v1、E9-07_v2 原件），3 个不可读容器（B05 失败 ipod 封装、F5 v4 视频、END03 ALAC 排练）。
6. 返工清单：E1-07 多人多城蒙太奇、E4-03 加班族反应、机房九屏九闸刀连续性、E9-01 到位后核对镜像场景、韩语延迟 1 s→0.5 s→同步。
