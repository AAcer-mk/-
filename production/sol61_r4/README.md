## F6 修复证据

实际原编码与 `art/candidates/F6-04_v3.png` 有十个手柄，与旧 QA 的“九个”表述冲突。原始图、原视频及旧 QA 原封保留。新图由内置 ImageGen 删除 x925 附近的多余装置，整张新图有连带变化，**只能取其小块空金属区域用于合成**。

修复蒙版原图坐标为 `[898,531,955,674]`，跟随原镜头的摄影推近、饱和度、亮度与晕影。原 480 帧在重新编码前直接复用原解码 RGB；最后 120 帧在蒙版之外逐像素一致。600 帧全部重新编码，最终视频字节不与旧版完全相同。实际编码回查确认九个装置；第五闸拉下后五个下拉、四个竖起，前五屏黑/后四屏绿。第 518 帧第五屏仍绿，第 519 帧黑；机械声仍在原 611.6 秒。键盘动作和命令画面保留。
