## 可复现构建

环境：Python 3.12、Pillow 12.3.0、numpy 2.3.5、带 libx264/libass/FLAC 的 ffmpeg；中文字体从原工程恢复，遵守原 OFL 许可。😂 使用系统 DejaVu Sans 的实际字形；不同系统须提供同一路径字体或修正 `emoji_path`，不得用乱码替代。

从仓库根目录执行，所有输出目录必须是新的：

```bash
python production/sol61_060902/restore_inputs.py --output ../source-b10 --cache ../verified-parts
python production/sol61_060902/render_e6_screens.py --source ../source-b10 --output ../e6-screen-rebuild
python production/sol61_060902/conform_e6_06_audio.py --source ../source-b10 --output ../e6-screen-rebuild
```

`RESTORE_INPUTS.json` 固定七个原始输入的路径、大小、TAR 偏移、SHA-256，以及 184 个依赖分卷的提交和 Git 对象。恢复脚本已在独立目录用已核验缓存实测通过，七份输出全部匹配原始字节。它不是完整工程恢复器；缺少的其他镜头需从原归档继续按需取回。脚本拒绝覆盖有冲突的现有文件，下载有界重试。

`render_e6_screens.py --live-video path.mp4` 可将 E6-02 静态底图换成完成后的 7.5 秒监控视频，保留既有 UI 和字幕结构。此参数要求足额 180 帧，不用静态图填补不足。
