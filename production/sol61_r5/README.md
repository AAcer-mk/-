## 画面制作

内置 ImageGen 生成12张原始摄影静帧：E7-01/06/08/09 各三张。全部原始 PNG、提示、尺寸和 SHA 保留，未把静帧候选计为动作片段。

大楼镜头以未亮灯底图固定全画面，只在审核过的主楼与地面反光区域转入正向光照差值；第4帧未亮，第5帧七层同时亮。七层实际编码亮度增量分别约53.8、65.1、56.6、63.9、54.2、57.0、38.0。初次混音能量瞬态在约709.20秒，画面亮灯为709.208333秒，相差约8.3毫秒。没有逐层亮灯或建筑变形。

纸海全景使用 R3 已有 DIS 光流合成，仅限定四个出纸区域；老韩、身体与区外背景在摄影变换前保持原底图逐像素一致。摄影从约4.8%推近位置缓慢后拉到全景。正方形对勾使用原 `native_scenes.mark('glm')`，透视投影在实景小黑屏中，已放大实际编码确认。它是局部纸运动工作版本，**不是 AI 生成的演员动作视频**，打印物理表现仍待导演精修。

对讲机复用原台词“韩师傅，您的退休申请也已批准。”及英文字幕；原对白为765.94–769.19秒。只从摄影静帧中取微小绿灯区域，在镜头内0.55–3.95秒接收状态亮起，不添加发射动作、头像、文字或新语音。

E7-06 只有三个拿纸静帧参考和字体/遮挡预览：申请事项值为不透明黑色块，批准意见为“同意。立即执行。”，原人物/两只手/纸面保留。选择v1；没有制作弯腰/捡起/拿起的连续动作，未增加该镜头180帧的完成计数。

## 声音与验证

三个新镜头母版及七镜头合集母版的无损 PCM 逐采样匹配相应原混音；合集音轨按各原区间的精确采样拼接，另行输入，避免 MKV 毫秒时间戳累积偏差。11个本地音画导出在制作进程结束后再次核对 SHA 并完整解码，均1920×1080/24fps、帧数正确，无削波。原生纸面文字、窗口开关、彩蛋、对白字幕和局部纸运动均回查实际编码。

混音仍是原工作版本：E7-01 可观察到约1秒重复的打击节奏；单次盖章与 M7 配乐的分离，以及 E7-08“心跳骤停”的最终声画设计尚待终审。未擅自削去整条混音或把逐采样复用称为正式声音表演验收。全片仍未完成正式演员/口型/声音及导演验收。

交付包保存三段独立无损母版、三段字幕 MP4、七镜头字幕合集 MP4、12个生成原图、拿纸预览、合成蒙版和校验/回查证据。重复本地清洁版、合集母版、源 WAV 与中间文件不重复打包；校验记录仍列出全部本地输出。精确保留清单与分片在 `PAYLOAD_MANIFEST.json`，远端全部分片和成员的重新下载/字节比对结果在 `REMOTE_RECEIPT.json`。
